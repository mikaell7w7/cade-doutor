# Cadê Doutor

Projeto de código aberto para facilitar a pesquisa na rede credenciada de saúde, com favoritos pessoais, histórico do catálogo e integração oficial Sign in with ChatGPT.

Implementação inicial em preparação. Fonte inicial: catálogo público TST Saúde, coletado em 17/11/2026.

O projeto é independente e não representa o TST, a OpenAI ou os prestadores cadastrados.
