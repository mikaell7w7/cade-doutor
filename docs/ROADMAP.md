# Roadmap

## 0.1: prévia local

Catálogo inicial, extensão Chrome, favoritos e backups, OAuth oficial, comparação por IA, mapa e avaliações sob demanda, plugin MCP de leitura, testes, CI e pacotes versionados.

## 0.2: assistente conversacional

Busca no catálogo completo por ferramentas, filtros e paginação; refinamentos com contexto; respostas formatadas, fichas e favoritos na conversa.

## Próxima validação

- Validar busca por ferramentas e refinamentos com uma conta real. Login e inferência simples foram observados na prévia 0.1.1; renovação e revogação reais ainda precisam de homologação.
- Homologar as APIs Google com projeto de faturamento e chaves restritas.
- Instalar a extensão no Chrome de uso diário e conferir a navegação no portal.
- Validar proteção de credenciais no Windows antes de divulgar suporte.
- Preparar identidade visual, screenshots, dados do desenvolvedor e revisão das lojas.

## Expansão priorizada

1. Assistente de instalação desktop, abertura automática do navegador e armazenamento no cofre do sistema.
2. Coletor reproduzível por adaptador, verificação de totais e atualização por pull request. O catálogo atual não possui coleta periódica automática.
3. Coordenadas de fontes compatíveis, correspondências revisadas persistidas somente quando permitido, seleção por raio e melhores controles do mapa.
4. Backup privado opt-in, incluindo repositório GitHub próprio com autorização mínima. Resolver conflitos sem expor notas ou localização no repositório de código.
5. Novas operadoras e normalização de prestador, estabelecimento e profissional.
6. Plugin remoto para ChatGPT web com autenticação própria e dados privados por usuário. Não reutilizar tokens locais do fluxo OSS como se autorizassem hospedagem remota.

Itens futuros não representam funcionalidades disponíveis na prévia.
